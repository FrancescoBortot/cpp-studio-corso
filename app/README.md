# Applicazione

Questa cartella contiene server, motore di compilazione, frontend, strumenti di generazione e test.

Nel repository pubblico devi prima aggiungere le fonti e rigenerare i contenuti
come descritto nel [README principale](../README.md#avvio-locale). Poi, dalla radice
del progetto:

```sh
python3 app/server.py
```

Consulta il [README principale](../README.md) e il [manuale](../docs/MANUALE.md). I materiali si trovano in `../materiali/`; report e cache in `../.local/`.
